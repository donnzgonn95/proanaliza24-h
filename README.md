Deutsch

Projektübersicht

ProAnaliza24-H ist eine webbasierte Anwendung zur strukturierten Beobachtung und Analyse von Kryptowährungsmärkten.

Das Projekt verbindet Marktdaten, regelbasierte Analyseverfahren und interaktive Visualisierungen. Ziel ist es, unterschiedliche Informationen in einer einheitlichen Benutzeroberfläche zusammenzuführen und die systematische Bewertung von Marktsituationen zu unterstützen.

Funktionale Schwerpunkte

- Marktdaten: Abruf von Kryptowährungsdaten über externe Schnittstellen, darunter Binance.
- Marktregime: Einordnung von Marktsituationen anhand verfügbarer Marktdaten.
- Setup-Analyse: Regelbasierte Generierung und Bewertung potenzieller Marktkonstellationen.
- Alarme: Aufbereitung relevanter Marktbewegungen und möglicher Signale.
- Watchlist: Beobachtung ausgewählter Assets.
- Dashboard: Interaktive Darstellung und Anpassung von Analysebereichen.
- Demodaten: Bereitstellung von Beispieldaten als Fallback, wenn Live-Daten nicht verfügbar sind.

Technische Architektur

Die Anwendung basiert auf einer modernen Webarchitektur mit serverseitigen Rendering-Funktionen und modular aufgebauten Komponenten.

Technologie-Stack

- React 19 und TypeScript
- TanStack Start und TanStack Router
- Vite
- Tailwind CSS
- Supabase-Clientbibliothek
- Lightweight Charts und Recharts
- Playwright für End-to-End-Tests

Datenverarbeitung und Analyse

Die Anwendung verarbeitet verfügbare Marktdaten und nutzt regelbasierte Funktionen zur Ableitung analytischer Ergebnisse.

Die Trennung von Datenbeschaffung, Analysefunktionen und visueller Darstellung erleichtert die Wartung und Weiterentwicklung der Anwendung.

Analyseergebnisse sind von der Qualität und Aktualität der Eingangsdaten abhängig. Nicht alle dargestellten Kennzahlen müssen auf Echtzeitdaten basieren.

Entwicklungsstand

Dieses Repository dokumentiert eine Entwicklungsvariante der Analyseplattform. Der tatsächlich verfügbare Funktionsumfang hängt unter anderem von der Datenverbindung, der Konfiguration externer Dienste und dem jeweiligen Implementierungsstand ab.

Einzelne Bereiche verwenden Demonstrationsdaten oder vereinfachte Darstellungen. Die vollständige Produktionsreife aller Module wird nicht vorausgesetzt.

Zielsetzung

Das Projekt dient als praktische Grundlage für die Entwicklung datengetriebener Anwendungen. Im Vordergrund stehen die strukturierte Verarbeitung von Informationen, regelbasierte Analyse, Visualisierung und die Unterstützung nachvollziehbarer Entscheidungen.

Die Anwendung ist ein Analysewerkzeug. Sie garantiert weder Prognosegenauigkeit noch finanzielle Ergebnisse und ist kein autonomes Handelssystem.

Polski

Opis projektu

ProAnaliza24-H to aplikacja internetowa służąca do systematycznej obserwacji i analizy rynków kryptowalut.

Projekt łączy dane rynkowe, regułowe metody analityczne i interaktywne wizualizacje. Jego celem jest zebranie różnych informacji w jednym interfejsie oraz wspieranie uporządkowanej oceny sytuacji rynkowej.

Główne obszary funkcjonalne

- Dane rynkowe: pobieranie danych o kryptowalutach z zewnętrznych interfejsów, w tym Binance.
- Reżim rynku: klasyfikacja sytuacji rynkowej na podstawie dostępnych danych.
- Analiza setupów: regułowe generowanie i ocena potencjalnych układów rynkowych.
- Alerty: opracowywanie informacji o istotnych ruchach rynku i możliwych sygnałach.
- Watchlista: obserwacja wybranych aktywów.
- Dashboard: interaktywna prezentacja danych i możliwość dostosowania sekcji analitycznych.
- Dane demonstracyjne: wykorzystanie przykładowych danych zastępczych, gdy dane na żywo nie są dostępne.

Architektura techniczna

Aplikacja wykorzystuje nowoczesną architekturę internetową, obejmującą renderowanie po stronie serwera oraz modułową strukturę komponentów.

Technologie

- React 19 i TypeScript
- TanStack Start i TanStack Router
- Vite
- Tailwind CSS
- Biblioteka kliencka Supabase
- Lightweight Charts i Recharts
- Playwright do testów end-to-end

Przetwarzanie i analiza danych

Aplikacja przetwarza dostępne dane rynkowe i wykorzystuje regułowe funkcje do wyprowadzania wyników analitycznych.

Oddzielenie pobierania danych, logiki analitycznej i prezentacji wizualnej ułatwia utrzymanie oraz dalszy rozwój aplikacji.

Wyniki analiz zależą od jakości i aktualności danych wejściowych. Nie wszystkie prezentowane wskaźniki muszą bazować na danych w czasie rzeczywistym.

Stan rozwoju

Repozytorium dokumentuje jedną z wersji rozwojowych platformy analitycznej. Rzeczywisty zakres dostępnych funkcji zależy między innymi od połączeń z danymi, konfiguracji usług zewnętrznych i stanu implementacji.

Niektóre sekcje wykorzystują dane demonstracyjne lub uproszczone prezentacje. Dokumentacja nie zakłada, że wszystkie moduły osiągnęły pełną gotowość produkcyjną.

Cel projektu

Projekt stanowi praktyczną podstawę do tworzenia aplikacji opartych na danych. Najważniejsze obszary to uporządkowane przetwarzanie informacji, analiza regułowa, wizualizacja oraz wspieranie decyzji, których podstawy można prześledzić.

Aplikacja jest narzędziem analitycznym. Nie gwarantuje trafności prognoz ani wyników finansowych i nie jest autonomicznym systemem handlowym.
